# Palace Guide

One note per palace in this folder (start from `templates/palace.md`). Rooms are `###` headings in **fixed walking order**; each spot is one bullet:

```markdown
- **<spot>** — "<your image, in your exact words>" → encodes [[Target Note]] (<what precisely, e.g. the 8 intermediates in order>) — added YYYY-MM-DD
```

**The rule that makes it work:** every image comes from *your* brain, in *your* words. Claude records verbatim, links each mnemonic to the knowledge note it encodes (and back-links from there), and helps you use it:

- `/palace walk <palace or room>` — rehearsal walk: you recall image + meaning at each spot before Claude confirms
- `/palace what <thing>` — which room encodes this?
- `/palace where <image>` — what does this image encode?
- `/palace suggest` — candidates worth palacing (lists, enumerations, constants) — you invent the imagery
- Or just describe a new mnemonic in any session and Claude files it here.
